## Repaired findings

Four earlier snapshots were rejected and are retired:

1. The first full driver rejected every real fixed-v6 producer because it
   treated its three documented progress lines on stderr as fatal.
2. The next driver did not bind the A and b files read by aggregation to the
   bytes accepted by their independent audits.
3. The first strict-certificate revision accepted `null` or arbitrary text in
   shard SHA fields and accepted JSON `false`, `true`, and integral floats as
   shard counts or `k` through Python's numeric equality rules.
4. The analytic-support comparison hashed host-specific device and inode
   numbers, so an independent checkout necessarily failed.  It also invoked
   isolated Python while attempting to control bytecode and hash behavior via
   environment variables; `-I` implies `-E`, making those variables inert and
   leaving unpinned ordinary pyc caches readable.

The frozen revision repairs each issue.  It admits only the three anchored
cached-v7 progress lines; binds all 26 audited shard byte strings and checks
them before and after aggregation/reconstruction; validates exact integer
types and lowercase SHA strings; compares all fresh aggregate values and
hashes with the regenerated shards; strips only validated host device/inode
identities from the support result; and runs every child with
`-B -I -X pycache_prefix=<fresh-private-empty-path>`.  The independent test
confirms that this path remains absent and that child bytecode writing is
disabled, isolated/environment-ignoring mode is active, and optimization mode
is propagated exactly.

## Replay dependency chain

The driver performs these checks in order, using a private temporary tree:

1. Hash all direct programs, candidate data, frozen exact inner result,
   analytic sources, support result, and tuple data before doing mathematics.
2. Re-run the hostile analytic-support proof.  Fresh and frozen canonical JSON
   must agree in every mathematical/status field.  Each snapshot must have the
   exact SHA and byte length and `nlink=1`; only positive `dev` and `inode`
   values are allowed to vary across hosts.
3. Run the separately pinned tuple verifier, which checks 48 distinct sorted
   entries, endpoints 0 and 236, and an omitted residue for every prime at
   most 48.
4. Reconstruct the D19 inner `I` and `48J` directly from the rational vector.
   The result must be byte-for-byte equal to the deterministic frozen direct
   result; no serialized matrix entry is read.
5. Regenerate all 13 D14 A shards.  A separately organized radial checker
   reconstructs every high, low, and band value, and its per-count SHA binds
   the exact generated byte string.
6. Regenerate all 13 cached-v7 Definition-5 mixed shards.  Each shard is
   passed to the pinned cached-v7 structural/result checker.  It validates the
   cache-only fields, normalizes exactly those fields to the fixed-v6 wire,
   and invokes the fixed-v6/v5/v3 audit chain to check exact branch geometry,
   `H=14-r`, active families, fixed-denominator arithmetic, and the single
   factor 48; its input SHA binds the generated byte string.
7. Recheck all 26 bound byte strings, aggregate through the pinned assembler,
   independently parse and sum the exact scalar fields, recheck all 26 bytes,
   and compare both the fresh aggregate and an externally SHA-pinned compact
   certificate against the reconstruction.
8. Recheck the driver, certificate, and every startup source/data snapshot
   after all child processes finish.

The subprocess API always receives an argument list and never enables a
shell.  Nonzero exits, timeouts, unexpected stderr, malformed progress,
noncanonical/duplicate-key JSON, incomplete count sets, source changes, and
output/hash disagreements are fatal.

## Exact projection identity

Write

```text
D = I(F) - 48 J(F),   A = I(H),   b = the exact mixed 48J form.
```

The inner and one-band supports are disjoint in the relevant `I` form.  For
the coefficient `t=b/A`, the exact quotient improvement is therefore

```text
48J(F+tH) - I(F+tH) = b^2/A - D,
```

so its sign is the sign of `b^2-A D`.  The replay recomputes, in integer-cleared
scales,

```text
I_scaled = 10^174 I(F),
D_scaled = 10^174 D,
A_scaled = 10^76 A,
b_scaled = 10^125 b,

margin = b_scaled^2 - A_scaled D_scaled,
quotient_lower_bound
  = 1 + margin/(A_scaled I_scaled + b_scaled^2).
```

All ten aggregate rational fields are independently recomputed from these
identities and compared in canonical reduced form.  A success requires
`A_scaled>0`, a positive denominator, `margin>0`, and an exact quotient above
one.  No matrix invertibility or positive-definiteness assumption is used.

audit only after all exact target shards land, a compact certificate is frozen
with an external SHA, and the default driver completes in normal and optimized
mode (or the exact deterministic outputs of both modes are otherwise compared).
The driver requires cached-v7 producer `b427...`, result checker `80ec...`, and
the 42-source cached-v7 assembler `08fb...`; it also enforces the exact cached
aggregate format, engine label, and fixed-v6 base-assembler SHA.  Any material
change to that stack requires a new source and result audit rather than
inheriting this verdict.
